JUMMAN UDDIN SURAD — PERSONAL PORTFOLIO WEBSITE
================================================

FILES
- index.html: page content
- styles.css: responsive layout and design
- script.js: mobile navigation, current year, contact form
- assets/: place your CV PDF and optional portrait here

BEFORE PUBLISHING
1. Open index.html in a browser to preview the website.
2. In index.html and script.js, replace every instance of YOUR_EMAIL@example.com with your real professional email.
3. Replace LinkedIn and GitHub placeholder URLs with your actual profile URLs.
4. Add your CV PDF as: assets/Jumman_Uddin_Surad_CV.pdf
5. To use your photo, save it as assets/profile.jpg and update the photo-placeholder element in index.html to an <img> element, then add CSS for the image.
6. Review all profile, experience, skills, certification, and project details. Remove anything that does not accurately describe your work.
7. Never upload passwords, private keys, confidential bank information, internal IP lists, or sensitive employer documents to a public website.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named jumman-uddin-surad.github.io (or another repository name you prefer).
3. Upload index.html, styles.css, script.js, and the assets folder to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then Save.
6. Wait for deployment and open the URL shown in Settings > Pages. It may take a few minutes.
7. Any future update: edit the files and commit/upload the changes; GitHub Pages will publish the updated site.

NOTES
- This is a static portfolio website; no paid hosting or backend is required.
- The contact form opens the visitor's email application. It does not send messages directly or store them on a server.
- A custom domain is optional and usually costs money; the GitHub Pages-provided address can be free.
